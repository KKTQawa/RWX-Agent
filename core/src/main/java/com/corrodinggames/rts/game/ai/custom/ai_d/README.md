# ai_d — 自定义 AI（注册码 22，`rwx.ai-rsi-1`）

策略写在四个模块里，共享一块 `Blackboard`；观测与下令全部走 `rsi_sdk`，不链接任何引擎类。

## 风格：因敌制胜——打得过就碾过去，打不过就拆他的战争能力

胜负条件是指挥中心，但**打法不总是冲家**。AI 每个战略拍先比一次双方兵力总量
（`enemyArmyPower` = 可见 + 最近 40 秒见过的敌方单位战力，`armyPower` = 我全军战力）：

| 局面 | 战略 | 具体行为 |
|---|---|---|
| **兵力不吃亏**（对方 ≤ 我 × 1.4） | **歼灭 / 收尾** | 直奔指挥中心；家里守得住就全军回防，守不住就把全军压出去换时间；不分兵 |
| **兵力吃亏**（对方 > 我 × 1.4） | **消耗 / 瓦解** | 战役目标换成拆产能（工厂 > 矿场 > 前哨 … > 指挥中心）、绕开他们主力、波次必须打得过守军才发、分出机动组扫荡、按需回防、集火与脱离接触 |

理由：对着 3.7 倍收入的对手，把兵送进他家门口是按对方最强的资源（产能）打；
但在我方不吃亏时绕圈子，等于把时间白送给对方的产能。**两种错误都致命**，所以按比例切换。
（实测：旧版对 Very Hard 78%，把消耗战规则无条件套上去掉到 65%——所以这一版把它做成开关。）

消耗战里的四条具体规则：

1. **逐步瓦解**：战役目标按"价值 / 路程 / 守军 / 路线中点敌战力"排序，
   优先拆工厂和矿场，指挥中心排最后。一座工厂没了就是对面 30 信用点/秒的产能下线。
2. **夺得主动权**：不因为一次骚扰就把全军拉回家。按威胁派兵——
   家里够挡住就继续压他们的经济，只有这股兵能吃掉我全军时才全员回防。
3. **歼灭有生力量**：只在"这一仗打得过"的地方接战；点的是**受伤的、值钱的、落单的**那一个，
   满编队里的坦克排在最后；队内战力比不过就脱离接触。
4. **机动组**：两个快速单位在敌方半场扫荡，找矿场/制造厂/落单工兵，逼他们分兵。
5. **回收**：空闲且没有建造任务的工兵去回收可见废墟（`RECLAIM`），长局多一条收入。

一句话：**别人拼产能，它先算打不打得过，再决定是碾过去还是拆他的产能。**

## 大图团战（3v3 / 4v4 / 5v5）四件事

团战和 1v1 的差别不在"战术"，在三条硬约束上：

1. **陆军到不了的地方，必须先知道它到不了**。每个战略拍按目标做一次可达性分桶
   （`canApproach`），多数单位到不了就把 `waterSeparated` 置真：排产偏 hover/air（×2.4/×1.6），
   并补建 `airFactory`——否则整支陆军站在家里等死（实测 `stuck` 常年 50–66 个单位）。
2. **目标要选"走得到"的**：`reachableTarget` 在最近的 12 个敌方建筑里挑一个
   "最多单位能走到"的，避免对着另一块大陆的指挥中心排队。
3. **打掉一家之后要换目标**：团战的胜负条件是**所有**敌方指挥中心。
   退役判据从"周围没有敌方建筑"改成"周围没有第二座活着的指挥中心"，
   否则军队会在尸体上站满 6 分钟的记忆时长。
4. **产能要跟得上收入**：工厂类型上限（10/6/2）与 `factoryMax=24`，
   `building()` 找地三级环 80–300 / 250–620 / 500–1000——基地挤满时也要能找到地方盖厂，
   不然就是"8 万信用点、0 座工厂、0 个兵"。

## 用到的通用技术（不是针对地图写的特例）

| 技术 | 在这里怎么用 |
|---|---|
| **ROI / 回收期投资** | 每个升级都有"多少钱换多少收入/秒"，用 `nextInvestment` 找到最便宜的待买项，收入按比例攒钱，攒够就买 |
| **影响力地图（influence map）** | `threatAt / armyPower / threatCentre`：基地与目标周围的敌方战斗力，用于选目标、判接战、按需派兵 |
| **兵力比交战规则** | 队内战斗力 vs 附近敌方战斗力，比值不过线就脱离接触（带回滞）；这是"不送兵"的硬闸门 |
| **目标聚类 / 绕行** | 战役评分里有两处敌方战斗力项：目标本身（守军）和**出发点与目标连线的中点**（路上会不会撞上他们主力） |
| **效用评分（utility）** | 兵种按"每信用点战斗力"排序；目标按"血量、价值、孤立程度、距离"打分 |
| **集中火力（focus fire）** | 每队每个决策拍一个集火目标，空闲单位都打同一个；比各自为战先打死人 |
| **波次状态机** | 集结 → 够强才出发（数量门槛 + 目标守军战斗力门槛）→ 打残后重新集结 |
| **指挥中心收尾** | CC 不是首选，但当它守军薄于我军战力×`ccGarrison` 时立刻全员集火——赢的是最后一下 |
| **命令回执自纠** | `orderFeedback` 里 `INVALID_PLACEMENT` → 把点拉黑 3000 tick；`INSUFFICIENT_CREDITS` → 当轮不再下单 |
| **废墟回收** | `view.salvage` + `Kind.RECLAIM`：没有建造任务的空闲工兵去回收可见废墟（长局里没人抢的收入） |
| **死基地退役** | 团战打掉一家后，靠"CC 失去视野 + 我方 ≥3 单位在附近 + 周边无敌方建筑"判定拆除，换下一个目标 |
| **盟友感知** | `view.allies` 参与矿点选址，两个 AI 不抢同一个矿 |
| **工厂集结点** | `Order.rally`（独立命令通道）把新兵直接指到前哨 |

## 三张表决定行为

**建筑价值**（`Knowledge.priorityOf`）—— 谁先拆：

| 建筑 | 价值 | 理由 |
|---|---:|---|
| 工厂 | 3.0 | 每座 ≈ 30 信用点/秒的产能，拆了就下线 |
| 采矿场 | 2.6 | 对面 3.7 倍收入，每座矿对他们都值我们 3.7 座 |
| 前哨/实验室 | 2.0 | 解锁与扩展 |
| 制造厂/维修 | 1.6 | 工兵与修理的根 |
| 指挥中心 | 1.0 | 赢的是最后一下，不是第一下 |
| 炮塔 | 0.12 | 最难啃、收益最低，绕开 |

**战役评分**（`Blackboard.campaign`）：

```
value / (1 + 路程/1500) / (1 + guardWeight × 目标处敌战力/我军战力)
                        / (1 + guardWeight/2 × 路线中点敌战力/我军战力)
```

**单位目标打分**（`CombatPlanner.bestTarget`）：血量 + 距离 − 价值 + 孤立惩罚；
建筑额外 `0.9 − 0.45 × priorityOf`，当前战役目标再 −1.2。

## 经济：投资地板

```
每 25 帧：
  pot += income × investShare × dt        // 固定比例攒钱
  target = min(所有待买升级价格 + 余量, 刺杀组价格)   // 最便宜的下一笔
  pot = min(pot, target)
  floor = (credits >= target) ? 0 : pot   // 攒够就松开地板
  Economy(work, reserve=0, productionCredits=0, economyCredits=floor)
```

- 排产模块拿到的 `availableCredits = credits - floor`，于是一边出兵一边攒钱，
  **不会出现"攒钱 8 秒被一波打穿"**。
- 地板在"买得起"的瞬间松开，避免地板把自己锁死（预算接口最容易踩的坑）。

## 已知短板

- **3.7 倍收入（Impossible）**：对手 100–250 单位，我方 20–50；单位效率只领先
  约 1.5 倍，补不上 3.7 倍产能差。拆经济能拖慢他们，但拖不垮。
- **机动组会被吃掉**：两三个单位在对方半场遇到主力跑不掉，只值"换来地图信息"。
  想真正牵制得靠运输机空投（`Logistics.Transport` + `LOAD/UNLOAD`，接口已支持，尚未使用）。
- **长射程单位（`mechLaser`）拿不到出手位置**：310 射程能白嫖炮塔，但整条链路
  （机甲厂 1000 + T2 4600 + 7000×3）经常在对局结束前攒不齐。
- **没有通信/阵形**：`RsiDecision.formation`（显式站位）还没用，
  现在靠引擎的群体移动阵形；`PATROL` 也不行（每 250 tick 重下一个巡逻点，永远走不到）。
