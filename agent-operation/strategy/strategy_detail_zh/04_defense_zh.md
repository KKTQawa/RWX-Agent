# 04 防守

[← 返回总览](../strategy_zh.md) · 上一篇：[03 侦查](03_scouting_zh.md) · 下一篇：[05 陆军进攻](05_offense_land_zh.md)

## 防守思路

火炮单位（资金充足时）搭配炮塔守家，是性价比很高的选择。**炮塔的作用不可小觑**：防御力上限与移动单位的进攻力上限相差无几（除非敌人真的很多）。

## 1. 陆地炮塔

| 炮塔 | 价格 | 特点与用途 |
|---|---|---|
| **T2 机枪** | — | 通用守家武器 |
| **T3 机枪** | 11000 | 范围广（仅次于 T2 火炮），攻速快，一般一个就能带来很高的防御力，但昂贵，**前期一般不使用** |
| **喷火器** | 500+700 | 专克普通机甲、tank、悬浮坦克等**以量取胜但血量很低**的单位；范围略小但血量高 |
| **电击塔** | — | 对**机甲单位**克制较好，自带护盾穿透，但攻速慢 |
| **T2 电击塔** | 昂贵 | 对高级机甲单位的打击是毁灭性的 |
| **火炮炮塔** | 升级需 1600 | **前期一般不使用**；其 T2 射程是游戏最远，非常适合阵地战推进战线 |
| **T2 火炮炮塔** | 昂贵 | 游戏最远射程，**前期一般不使用** |

## 2. 防空

- **2 级防空炮塔**（600+1200）：阵地防守的常规选择。**1 级防空炮塔只能形成很弱的防守。**
- **高射炮**（4000）：射程略小，但群伤高，也是不错的选择，较昂贵。
- **T3 防空炮塔**（12000）：防空能力极高、攻击范围远，但价格昂贵。
- **重型拦截机**：对付空军的有力武器，攻速快、移动高。
- **防空机甲**：性价比很高，范围伤害，血量适中。

## 3. 维修湾与激光防御塔

- **维修湾**（1500）：如果部队中有**血量高的高级单位**，应善用它修复受伤部队。**资金紧缺时最多造一个**；有炮塔前线时，尽量覆盖炮塔。
- **激光防御塔**：用途很多，最常见的是防御**敌军火炮单位的攻击**；花费 2000 升到 2 级的做法也很常见。

## 4. 火炮单位防守

- T2 陆军工厂生产的**重型火炮**（2000+）
- 1 级机甲工厂的**火炮机甲**（1700）

## 5. 按威胁选防守【补充】

| 敌方威胁 | 推荐应对 |
|---|---|
| 大量低血量单位（普通机甲、tank、悬浮坦克） | 喷火器 |
| 机甲为主（尤其高级机甲） | 电击塔 / T2 电击塔 |
| 空军（武装直升机等） | 2 级防空炮塔；防空机甲；重型拦截机；高射炮（群伤） |
| 大规模空军后期 | T3 防空炮塔；重型拦截机 |
| 敌方火炮单位远程压制 | 激光防御塔（可升 2 级）；自己的火炮单位反制 |
| 需要稳固的通用守家 | T2 机枪 |
| 需要推进阵地战线 | T2 火炮炮塔（贵，后期用） |

## 6. 防线布置要点【补充】

- 占据据点后**立刻**建炮塔，再补防空（见 [02 据守据点](02_economy_zh.md)）。
- 维修湾尽量覆盖炮塔，让前线炮塔持续恢复。
- 前期不要被昂贵的 T3 机枪、火炮炮塔拖垮经济；先用 T2 机枪 + 针对性炮塔（喷火器/电击塔）。
- 防空要随敌方空军规模提升：1 级不够，升 2 级；再不够考虑高射炮或 T3。
