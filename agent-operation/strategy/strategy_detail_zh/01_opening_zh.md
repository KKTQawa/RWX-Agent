# 01 开局与资源点

[← 返回总览](../strategy_zh.md) · 下一篇：[02 经济与扩张](02_economy_zh.md)

## 开局行动清单

1. **生产建造者**——不管局势如何，这都是常规动作。
2. **扫描全图资源点**——资源点的位置可以无视迷雾查看。大多数地图在基地附近就至少有一个资源点。
3. **没有部队时，只能做两件事**：升级矿脉、建造炮塔。
4. **分析地图战略要地**，决定扩张方向。**不要让大多数资源点落入敌手**，否则会处于压倒性劣势。
5. **确认经济倍率与收入档位**，据此决定出兵方向（见 [02 经济与扩张](02_economy_zh.md)）。

## 为什么资源点最重要

中小型地图的资源点并不多。开局就掌握分布、分析战略中枢，才能决定扩张策略。资源点数量直接决定后续收入档位，一旦大部分落入敌手，几乎无法靠操作弥补。

## 资源点分析方法【补充】

- 把资源点按归属分三类：**己方近点**、**中间争夺点**、**敌方近点**。
- 先稳住并升级近点，再去抢中间点。
- 抢到的点必须能守住：占据后立即建炮塔（见 [02 据守据点](02_economy_zh.md)）。
- 同时关注地形：孤岛、山地、岩浆会改变“谁能到达、谁能攻击”（见 [09 地形](09_terrain_zh.md)）。

## 开局检查清单【补充】

- [ ] 建造者已在生产
- [ ] 基地附近的矿脉已在升级
- [ ] 已扫描全图资源点并分类
- [ ] 已确认经济倍率（x1 / x1.5 / x2+）
- [ ] 首座炮塔已安排
- [ ] 已大致判断对手类型/方向，决定是否需要尽早侦查（见 [03 侦查](03_scouting_zh.md)）

## 常见开局错误【补充】

- 不看资源点分布，盲目出兵。
- 余额长期闲置（见 [10 机制](10_realtime_zh.md)）。
- 前期投入昂贵的 T3 机枪或火炮炮塔（这些**前期一般不使用**，见 [04 防守](04_defense_zh.md)）。
