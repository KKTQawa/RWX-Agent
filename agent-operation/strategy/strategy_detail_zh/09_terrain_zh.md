# 09 地形与战场

[← 返回总览](../strategy_zh.md) · 上一篇：[08 战术](08_tactics_zh.md) · 下一篇：[10 实时指挥与机制](10_realtime_zh.md)

## 山地为主的山区

- 在**山地面积广且繁杂**的地形，**机甲单位**优势明显。
- 火炮机甲、机枪机甲等中高级机甲单位都可以**无视山地阻挡**。

## 孤岛

如果敌人在孤岛上建设据点，常见进攻方式有：

1. **空军**
2. **海军**（岛屿面积小，刚好在覆盖范围内时）
3. **设法运输陆军进攻**
4. **先夺取沿海岸的制海权**：用海军、火炮对轰、T3 机枪射击等远程打击，然后在火力掩护下建设野生据点（海上建造者通常是很好的选择），就地生产部队

## 跨海战斗

- 海军的**防空**通常是大问题。
- 很多时候海军**并不能完全摧毁**敌人据点，除非敌人所有重要建筑都能被沿海舰队打到。
- 使用陆军悬浮单位主力：**重型气垫坦克**，各方面居中，对地对空。

## 岩浆区

- 海军完全无法使用。
- 但岩浆并不能隔绝**炮塔攻击、火炮攻击**。

## 地形—兵种速查【补充】

| 地形 | 优先考虑 | 注意 |
|---|---|---|
| 山地 | 机甲（火炮机甲、机枪机甲） | 机甲怕电击、火炮 |
| 孤岛 | 空军、海军、运输陆军；先夺制海权再建据点 | 海军防空是短板 |
| 跨海 | 重型气垫坦克 | 海军难以完全摧毁据点 |
| 岩浆区 | 炮塔、火炮 | 海军无法使用 |
