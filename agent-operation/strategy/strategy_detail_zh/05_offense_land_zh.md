# 05 陆军进攻

[← 返回总览](../strategy_zh.md) · 上一篇：[04 防守](04_defense_zh.md) · 下一篇：[06 空军进攻](06_offense_air_zh.md)

> 以下是适合人类玩家的部分经验打法，**仅供参考**。

## 重型坦克 + 等离子坦克

- 2 级陆军工厂生产，价格实惠，常出现在人海战术中。
- 害怕：火炮单位、实验坦克等炮击单位。

## 机枪机甲

性价比极高的高级单位，移动灵活、**无视山崖**、攻速高，常在人类对局中大显身手。

- **生产**：需要 T2 机甲工厂（1000+5000），单价 4500+。
- **优势**：可偷袭 T1 炮塔和 T2 机枪，吊打大多数中低级单位。
- **弱点**：不对空（常搭配 2 个以上防空机甲护卫）；害怕电击塔、火炮、猛犸坦克。

## 钢铁洪流

以各种**中高级陆军主力**为主的人海战术，包括：重型坦克、等离子坦克、猛犸坦克、机枪机甲、喷火机甲、防空机甲/重型防空机甲/防空导弹坦克。

## 重型气垫坦克

属性中等，属于中级悬浮主力。虽然移速较慢，但在某些局势下依然受人类玩家青睐（跨海战斗见 [09 地形](09_terrain_zh.md)）。

## 陆军弱点速查【补充】

| 单位 | 主要弱点 |
|---|---|
| 重型坦克 / 等离子坦克 | 火炮单位、实验坦克 |
| 机枪机甲 | 无对空；电击塔、火炮、猛犸坦克 |
| 低血量人海（普通机甲、tank、悬浮坦克） | 喷火器 |
| 机甲类 | 电击、火炮 |

## 搭配建议【补充】

- 机枪机甲 + **2 个以上防空机甲**护卫，补足对空。
- 钢铁洪流内含对空单位（防空机甲/重型防空机甲/防空导弹坦克），不要只带对地。
- 山地多的地图优先考虑机甲（见 [09 地形](09_terrain_zh.md)）。
- 对手有大量炮塔/火炮时，避免纯重坦硬冲；可先用激光防御塔、火炮反制（见 [04 防守](04_defense_zh.md)）。
